## macOSでの操作確認

環境: macOS 26.6.2（25G83）、Apple Silicon ARM64、Rust 1.96.0、Node.js 24.3.0。素材を同梱したTauriアプリを起動し、架空のデッキのみを使用した。

- CSV列選択→差分プレビュー→適用。初回3枚を作成。
- 答えを隠して出題→Spaceで表示→3で評価→取り消し。枚数と履歴の変化を確認。
- 30日予測と、学習済みカードの忘却曲線をネイティブWebViewで表示。
- パスフレーズ暗号化バックアップをファイル選択・保存ダイアログから作成し、復号・プレビュー・全体復元。
- Release APPの再起動で3枚・1回の学習履歴が引き継がれることを確認。
- 列順の異なる更新CSVで追加1・更新1・変更なし1・CSVから消えたカード1をプレビュー。適用後、旧3枚の内部IDと復習状態がすべて一致することをSQLiteの読み取りで照合。
- 当日上乗せで表示上限が20→30枚へ変わることを確認。
- 4枚・上乗せありの状態からバックアップ時点の3枚・1履歴・上乗せなしへ全体復元。退避DBには復元前の4枚と上乗せが残ることを確認。

起動済みアプリのプロセスに対する`lsof -a -nP -p <PID> -i`ではネットワークソケットを検出しなかった。これは時点観測であり、WebViewの補助プロセスを含む全操作の通信検証は未完了として扱う。

成果物は`artifacts/Kotoba.app`と`artifacts/Kotoba_0.1.0_arm64.dmg`。実行ファイルはリンカーのad-hoc署名で、Developer IDによる署名・公証は未実施。Tauri標準のDMG作成スクリプトが失敗したため、APP作成後に`hdiutil`でDMGを作る再現可能なスクリプトを用意した。
