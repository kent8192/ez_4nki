# 学習データの処理を端末内に限定する

Highly Confidentialに該当する教材を本人と数人が扱うため、初期方針として、取り込み・学習・分析を端末内で完結させ、学習データの持ち出しを利用者の明示操作による暗号化バックアップに限定する。自動同期やサーバー側分析を採用すると学習データの信頼境界が端末外へ広がるため、それらを前提とする構成は採らない。各利用者は独立してCSVを取り込み、バックアップは3 OS間で復元できるものとし、端末内の保護は[ADR-0002](0002-rely-on-os-for-local-protection.md)に従う。

バックアップはパスフレーズで開き、全単語帳・学習履歴・FSRS設定を全体復元する。初版は更新確認を含めアプリによる通信を行わず、新しいインストーラを利用者が手動で適用する。
