# 重複問題の統合と選択肢の取り込み

2026-09-10の利用者の要望により、CSV内の同じ問題を1枚にまとめる。選択肢は1列にまとめて記載する形式を主な利用形態とする。

既存の照合規則は維持する。IDなしでは問題文の完全一致、IDありではIDが一致する行を対象にする。同じキーかつ同じ問題文の行をまとめ、答え・解説・選択肢の同一内容を一度だけ残す。異なる答え・解説は出現順に空行で区切り、プレビューに注意文と元の行番号を示す。IDを使って区別した問題や複数の既存カードの学習履歴を自動的に合併しない。同じIDに異なる問題文がある場合は適用を止める。

選択肢は選択したセル全体をプレーンテキストとして保持するのが既定。改行または明示した区切り文字で分割することもできる。複数列を選ぶ場合は列順を保つ。見出しと内容を保存し、問題と同時に表示する。答えは開くまで隠し、FSRSへの評価は本人が行う。

カードの選択肢、列割り当て、区切り設定を保存・暗号化バックアップに含める。形式を2に進め、旧形式1は選択肢を空にして読めるようにする。DBは読み込み・内容検証に成功してから版を更新する。旧アプリが選択肢を落として保存しないよう、新形式を旧版へ戻す機能は設けない。
